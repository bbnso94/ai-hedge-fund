# Peoria Garden Plan 2026 (PDF)

This folder includes a polished, printable PDF version of the Peoria, IL planting schedule based on packets **#1-#9**.

## Files

- `docs/peoria_garden_plan_2026.pdf` - final 3-page visual planting guide.
- `docs/images/peoria_garden_plan_preview.png` - first-page preview image.
- `scripts/generate_peoria_garden_pdf.py` - script used to generate the PDF.

## Regenerate

```bash
python scripts/generate_peoria_garden_pdf.py
```

The script uses Pillow only (no external dependencies).
